# Stage 6: Deliver

## Entry Criteria
- [ ] Stage 5 evidence is complete
- [ ] No unresolved review findings

## Activities
1. Summarize the change, scope, verification actually performed, and any unverified risk.
2. Update the relevant `.claude/` rule, workflow, skill, and reference files when behavior or tooling changes.
3. For release candidates, record—not infer—the candidate SHA, successful PostgreSQL/MySQL Actions runs, and RA2 GUI artifacts. A tag triggers CI/release automation but is not proof that a release has published.
4. Commit, tag, publish, or distribute only with explicit authorization and after the required evidence succeeds.

## Exit Criteria
- [ ] Delivery summary distinguishes observed evidence from pending work
- [ ] Documentation is synchronized with the delivered behavior
- [ ] No release claim is made without a successful, observed release result
